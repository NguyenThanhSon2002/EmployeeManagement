# Archive Documentation (Lưu trữ tài liệu kế hoạch cũ)

Thư mục này lưu trữ các tài liệu kế hoạch, lộ trình triển khai ban đầu và các biên bản thảo luận trong quá trình khởi tạo dự án. Các tính năng liên quan đã được hiện thực hóa và kiểm thử thành công trong mã nguồn.

### Danh sách tài liệu lưu trữ:
- `00-assumptions-and-decisions.md`: Giả định và quyết định kỹ thuật ban đầu.
- `09-frontend-decisions.md`: Quyết định kiến trúc frontend sơ khởi.
- `10-frontend-architecture-plan.md`: Kế hoạch kiến trúc frontend ban đầu.
- `13-frontend-mock-data-plan.md`: Kế hoạch xây dựng mock data giai đoạn dev UI.
- `14-frontend-test-and-quality-plan.md`: Kế hoạch kiểm thử chất lượng ban đầu.
- `15-frontend-implementation-roadmap.md`: Lộ trình triển khai frontend qua các giai đoạn.
- `16-frontend-traceability.md`: Bảng truy vết yêu cầu phần mềm ban đầu.
- `17-backend-brainstorm-and-plan-summary.md`: Tóm tắt phiên thảo luận và kế hoạch backend.
